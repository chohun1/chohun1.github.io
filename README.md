# Hun Cho · 조훈 포트폴리오

GitHub Pages에 게시할 수 있는 정적 포트폴리오입니다. 노션의 ‘안녕하세요, 조훈입니다’ 페이지를 바탕으로 2026-10-08에 구성한 초안입니다. 노션 변경 사항은 자동 반영되지 않습니다.

## 파일

- `index.html`: 영문 기본 페이지
- `academic.css`: 영문 연구자 포트폴리오 스타일
- `ko.html`: 기존 한국어 페이지
- `style.css`: 데스크톱·모바일 화면과 인쇄 스타일
- `favicon.svg`: 사이트 아이콘
- `.nojekyll`: 정적 파일 게시 설정

## 게시

- 계정: `chohun1`
- 저장소: https://github.com/chohun1/chohun1.github.io
- 사이트 주소: https://chohun1.github.io

저장소의 Settings → Pages → Source에서 **Deploy from a branch**를 선택하고, `main` 브랜치의 `/ (root)`를 게시합니다. 파일 변경을 `main`에 저장하면 GitHub Pages가 사이트를 갱신합니다.

## 수정과 미리보기

영문 내용은 `index.html`, 스타일은 `academic.css`를 수정합니다. 한국어 내용은 `ko.html`, 스타일은 `style.css`를 수정합니다. 두 언어는 각각 편집해야 합니다. 브라우저에서 `index.html`을 직접 열어도 볼 수 있습니다. 서버 미리보기가 필요하면 해당 폴더에서 `python -m http.server 5180 --bind 127.0.0.1`을 실행하고 출력된 주소로 접속합니다.

공개 전 이름, 이메일, 재직·학력 정보, 연구·과제 설명, 시연 영상의 공개 범위를 확인하세요. 역할과 결과는 원문에 근거해 작성했으며, 자격증은 취득 완료가 아닌 준비 중으로 표시했습니다.
